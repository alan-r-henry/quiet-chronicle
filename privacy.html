Privacy Policy

Quiet Chronicle uploader · last updated 12 October 2026

The Quiet Chronicle uploader (“the uploader”) is a private program that runs only on the computer of the owner of the YouTube channel The Quiet Chronicle, and is used only by that person, for that channel. This policy explains what it does with data.

YouTube API Services

The uploader uses YouTube API Services to upload the channel's own videos. By using it you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy (https://policies.google.com/privacy).

What data it accesses

  • Google sign-in: when the channel owner signs in, Google gives the uploader an access token and a refresh token for two permissions: uploading videos (youtube.upload) and managing the channel's captions and playlists (youtube.force-ssl).
  • The channel's own videos and playlists: the uploader sends the owner's video files, titles, descriptions, thumbnails and captions to YouTube, and reads the names of the channel's own playlists to find the one a video belongs in.

It does not access data about viewers, subscribers, comments, analytics, or any other channel.

How it uses, stores and shares data

  • The sign-in tokens are stored only in one file on the owner's own computer (token.json). They are used only to make the uploads described above.
  • After an upload, the uploader keeps a small record on the same computer (upload.json: the video's YouTube ID and which upload steps finished), so that it never uploads the same video twice.
  • Nothing is sent anywhere except to Google's own YouTube and sign-in services. No data is sold, shared with third parties, or used for advertising.
  • The uploader is not a website or app for others: it sets no cookies, collects no analytics and has no other users. This web page itself sets no cookies.

Taking back access and deleting data

  • Access can be revoked at any time on Google's security settings page: https://myaccount.google.com/connections (Third-party apps & services → Quiet Chronicle uploader → Delete all connections).
  • Or run the uploader's sign-out command (upload --sign-out): it revokes the access at Google and deletes the stored tokens straight away.
  • Deleting the uploader's folder on the computer deletes everything else it stored. When access is revoked, the uploader stores and uses no YouTube data until the owner signs in again.
